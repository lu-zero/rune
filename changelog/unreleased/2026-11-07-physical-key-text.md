- **Physical keys carry the platform's text.** `PhysicalInput::Key` gains `text` and `consumed_mods`. A window fills them from the key event: `text` is what the platform produced, and `consumed_mods` is the modifiers it spent when that string differs from the unmodified key. A scripted key's paired text is copied onto the physical event when `text` is still empty. The enum is no longer `Copy`; `text` is zeroized on drop.
